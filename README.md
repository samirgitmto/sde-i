# Software Engineering Learning Repository

A personal monorepo containing my learning, practice, experiments, and reference material across software engineering topics.

## Contents

| Directory | Description |
|---|---|
| `Java/` | Core Java concepts, examples, and experiments |
| `DSA/` | Data Structures and Algorithms practice |
| `Coding rounds/` | Coding-round and interview problem solving |
| `design patterns/` | Design patterns and related implementations |
| `Spring Boot/` | Spring Boot learning and projects |
| `Spring Boot Advanced/` | Advanced Spring Boot concepts and experiments |
| `DBMS/` | Database and DBMS concepts |
| `Frontend/` | Frontend development practice |
| `mutithreading/` | Java concurrency and multithreading |
| `reactive-programming/` | Reactive programming concepts and experiments |
| `code_2025/` | Code and practice from 2025 |
| `code_2026/` | Code and practice from 2026 |
| `eBooks/` | Technical books and reference material |
| `experts-talks/` | Notes and material from technical talks |

## Purpose

This repository serves as a single place for:

- Learning and experimentation
- DSA and coding-round practice
- Java and Spring development
- Understanding software design and architecture
- Concurrency and reactive programming
- Notes and technical references

## Structure

The repository is organized primarily by topic, with year-based directories retained for older/general-purpose code.

## Notes

Generated files and development artifacts such as `.class`, `.jar`, build directories, IDE metadata, and PDFs are excluded through `.gitignore`.
